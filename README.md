# FitMood / 今天穿什么

FitMood 是一个面向移动端的智能衣橱与穿搭推荐 PWA，支持本地图片衣橱、审美规则引擎和穿搭历史反馈。

在线预览：[https://zzy-sudo-acm.github.io/FitMood/](https://zzy-sudo-acm.github.io/FitMood/)

## 核心功能

- 本地衣橱管理：新增、编辑、删除衣物，并按分类筛选。
- 衣物图片上传：支持本地上传衣物照片，生成缩略图用于衣橱和推荐卡片。
- IndexedDB 图片存储：压缩后的衣物图片保存在浏览器本地 IndexedDB。
- 今日穿搭推荐：根据体感、天气、场合、心情和活动量生成完整 outfit。
- 审美分析详情：从色彩、比例、风格、场合、天气舒适 5 个维度解释推荐理由。
- 穿搭历史与反馈：记录穿过的搭配，并用喜欢、踩雷、不舒服等反馈影响后续推荐。
- 设置与偏好：支持怕冷程度、推荐偏好、默认风格偏好、主题和开发者模式。
- 本地隐私保护：所有衣橱数据都保存在用户自己的浏览器中。
- 导出 / 导入备份：支持导出衣橱、历史和设置，并从备份文件恢复。

## 架构说明

FitMood 目前是纯前端 PWA，不依赖后端服务。

- `localStorage` 存储衣物元数据、穿搭历史、设置、主题和开发者模式。
- `IndexedDB` 存储压缩后的衣物图片 Blob。
- `imageThumb` 存储在衣物元数据中，作为衣橱卡片、推荐卡片和备份恢复时的轻量缩略图兜底。
- 备份文件会导出衣物、历史、设置、`exportedAt`、`appVersion` 和 `schemaVersion`。
- 当前备份主要用于恢复元数据和缩略图；完整原图仍保存在原浏览器的 IndexedDB 中，不会被写入备份文件。

## 推荐系统

推荐流程分为几步：

1. 硬过滤：排除未清洗、雨天不适合、场合明显不匹配或天气明显不适合的单品。
2. 候选搭配生成：组合上装/下装/连衣裙/外套/鞋子，并尝试加入包和配饰。
3. 多维规则打分：根据审美规则引擎计算各维度分数和自然语言解释。
4. 历史反馈降权：近期穿过或曾经踩雷的单品会降低推荐权重。
5. 高分候选加权选择：在高分候选中保留一定随机性，让“换一套”有变化。

## 审美规则引擎

FitMood 的推荐不调用 AI API，而是使用可解释的本地规则：

- 色彩协调：关注主色、辅助色、中性色、明度、饱和度、冷暖和花纹数量。
- 版型比例：关注上短下长、腰线、松紧平衡、长外套和行动风险。
- 风格一致性：判断风格标签是否集中，以及通勤、温柔、运动、辣妹等风格是否冲突。
- 场合礼仪：针对面试、通勤、上课、约会、拍照、运动、宅家等场景调整权重。
- 天气舒适：结合体感、怕冷程度、厚度、保暖度、雨天、大风和活动量做舒适判断。

## 隐私说明

- 衣物图片只保存在用户本机浏览器。
- 不上传到服务器，不接云存储。
- 不接外部 AI API，也不做云端图像识别。
- 清空浏览器站点数据可能会删除本地衣橱、历史和图片，建议定期导出备份。

## 本地运行

## 部署说明

项目部署到 GitHub Pages，Vite 的 `base` 配置为 `/FitMood/`。

GitHub Pages 需要在仓库设置中启用 GitHub Actions 部署。当前工作流会依次执行 Checkout、Setup Node、Install dependencies、Test、Build、Configure Pages、Upload artifact 和 Deploy to GitHub Pages。
